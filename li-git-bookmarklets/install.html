Installer le bookmarklet

  1. Affiche la barre de favoris : Cmd+Shift+B.
  2. Fais glisser les boutons bleus dans la barre de favoris (ne clique pas dessus ici).

li → github github → li

Utilisation : sur un profil LinkedIn (classique ou Recruiter Lite), clique sur le favori. Un panneau s'ouvre : liens GitHub deja presents sur la page, bouton « Classer les comptes GitHub (API) », puis recherches GitHub et Google pretes a cliquer. Nom, lieu et entreprise sont lus sur le profil et restent modifiables. Re-cliquer le favori ferme le panneau.

github → li : sur un profil GitHub (github.com/pseudo), clique sur le favori. Le bouton « Trouver le vrai nom » lit le nom et l'email signés dans ses commits publics (comme le .patch d'un commit), puis propose les recherches LinkedIn et Google.

Token GitHub (demande au clic sur le bouton API) : github.com/settings/tokens > Generate new token (classic), aucune case cochee. Pour ne plus le saisir, mets-le dans li-git-bookmarklets/.env (GITHUB_TOKEN=...) et utilise install_local.html.
